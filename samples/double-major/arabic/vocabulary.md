One deck for all reading vocab since Sept 2025, so it's one queue in the morning. A heading per source so I can find where a word came from. Front: the word as it appears plus the imperfect / plural where it matters, vowelled. Back: meaning, then root and form in brackets. Root letters in Latin because Arabic letters with hyphens come out in the wrong order half the time. Long ones (with an example sentence from the text) are written on several lines.

Conventions: "ج" = plural, "I a/u" = perfect/imperfect stem vowels, roman numeral = verb form. If the example sentence is from a passage, it's copied exactly; otherwise it's mine and probably needs checking.
