## lecture 9 · the variational principle

Typed up from the notebook the same evening. Any trial state gives an upper bound on the ground-state energy, so the best trial state in a family is the one with the lowest expectation value.

So $\langle \psi | H | \psi \rangle \ge E_0$ for any normalized $\psi$, with equality only for the ground state itself.
